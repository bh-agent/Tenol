# 테놀 앱스토어 출시 플랜

## 사업자등록 필요 여부

### 결론: 현재는 불필요, 유료화 시 필요

| 상황 | 사업자등록 | 통신판매업 신고 |
|------|-----------|----------------|
| **무료 앱 배포 (현재)** | 불필요 | 불필요 |
| 유료 앱 또는 인앱 결제 도입 시 | **필수** | **필수** |
| 광고 수익 연 600만원 초과 시 | **필수** | - |

테놀은 현재 무료 앱이므로, **개인 개발자로 등록하면 사업자등록 없이 출시 가능**.
향후 유료 구독이나 인앱 결제를 추가할 때 사업자등록 진행하면 됨.

---

## STEP 1: Apple Developer 등록 (1-2일)

### 준비물
- [x] Apple ID (iCloud 계정)
- [ ] 신용/체크카드 (연회비 $99 결제용)
- [ ] 본인 명의 휴대폰 (2단계 인증)

### 절차
1. https://developer.apple.com/programs/enroll/ 접속
2. **"개인(Individual)"** 선택 (조직 아님 — 사업자등록 불필요)
3. Apple ID로 로그인
4. 본인 확인 정보 입력:
   - 법적 이름 (영문): 여권 영문 이름
   - 전화번호
   - 주소 (영문)
5. $99/년 결제
6. Apple 승인 대기 (보통 24-48시간)

### 주의사항
- 개인 등록 시 D-U-N-S 번호 불필요
- 앱스토어에 **개인 이름**이 개발자로 표시됨 (회사명 X)
- 향후 법인/사업자로 변경 가능

---

## STEP 2: Google Play Console 등록 (즉시~14일)

### 준비물
- [ ] Google 계정
- [ ] 신용/체크카드 ($25 일회성 결제)
- [ ] 본인 명의 신분증 (주민등록증 또는 운전면허증)

### 절차
1. https://play.google.com/console/ 접속
2. **"개인"** 계정 유형 선택
3. 개발자 정보 입력:
   - 개발자 이름 (한글 가능)
   - 이메일 주소
   - 전화번호
   - 웹사이트: https://tenol-one.vercel.app
4. $25 일회성 결제
5. 본인 인증 (신분증 사진 업로드)
6. **신규 계정 14일 대기** 후 앱 출시 가능 (Google 정책)

### 한국 개발자 추가 요구사항
- 문의 전화번호 필수 제공
- 개인정보처리방침 URL: https://tenol-one.vercel.app/privacy (이미 있음)
- 유료 앱/인앱 결제 시: 사업자등록번호 + 통신판매업 신고번호 필요

## STEP 3: 앱 에셋 준비 (1-2일)

### 앱 아이콘
- [ ] 1024x1024px PNG (투명 배경 X, 모서리 둥글게 X)
- 배경: #0A0A0A 또는 #00E676
- 로고: 테놀 로고 중앙 배치
- Apple/Google 모두 같은 아이콘 사용 가능

### 스크린샷 (필수)
캡처 필요한 화면 (실제 앱 데이터로):

| # | 화면 | 설명 |
|---|------|------|
| 1 | 클럽 목록 | "내 클럽을 한눈에" |
| 2 | 경기 상세 | "경기 참가 관리" |
| 3 | 대진표 | "자동 대진표 생성" |
| 4 | 경기 결과 | "결과 기록과 공유" |
| 5 | 클럽 통계 | "상세한 통계 분석" |

#### 사이즈
- **iPhone 6.7"**: 1290 x 2796px (필수)
- **iPhone 6.5"**: 1284 x 2778px (권장)
- **Android 폰**: 최소 1080px 너비, 16:9 또는 그 이상

### 앱 설명문

**짧은 설명 (80자 이내):**
> 테니스 클럽 운영의 모든 것. 경기 생성, 대진표, 점수 기록, 통계까지.

**긴 설명:**
> 테놀은 테니스 클럽 운영을 위한 올인원 앱입니다.
>
> 주요 기능:
> - 클럽 생성 및 멤버 관리
> - 경기 생성, 참가자 관리, 대기열
> - 자동 대진표 생성 (혼복/남복/여복/자유)
> - 실시간 점수 입력 및 결과 기록
> - 개인/클럽 통계 및 랭킹
> - 반복 경기 템플릿
> - 게스트 모집 게시판
> - 경기 결과 이미지 공유
>
> 테니스 동호회, 사내 테니스 클럽, 레슨 그룹 등
> 테니스를 함께 즐기는 모든 모임에서 사용하세요.

## STEP 5: iOS 빌드 (Mac 필요)

### 필요 장비
- Mac (대여 가능: MacStadium 월 $50~, 지인 Mac 빌리기)
- Xcode 최신 버전 (무료, App Store)

### 절차
1. `npx cap open ios` — Xcode 프로젝트 열기
2. Xcode → Signing & Capabilities → Apple Developer 계정 연결
3. Bundle Identifier: `app.tenol.club`
4. 아이콘 추가 (Assets.xcassets)
5. Product → Archive → Distribute App → App Store Connect
6. App Store Connect에서 앱 정보 입력
7. 심사 제출

### Apple 심사 주의사항
- WebView 래퍼 앱 거절 가능 — 네이티브 기능 1개 이상 추가 권장
  - 추천: 푸시 알림 (`@capacitor/push-notifications`)
- 심사 기간: 보통 1-3일
- 거절 시 사유 확인 후 수정, 재제출 가능

## STEP 6: Android 빌드

### 필요 소프트웨어
- Android Studio (Windows/Mac/Linux, 무료)

### 절차
1. `npx cap open android` — Android Studio 프로젝트 열기
2. app/build.gradle → applicationId: `app.tenol.club`
3. 아이콘 추가 (Android Studio → Image Asset)
4. Build → Generate Signed Bundle (AAB 파일)
5. Google Play Console에서 앱 생성
6. AAB 파일 업로드
7. 스토어 정보, 스크린샷 입력
8. 내부 테스트 → 비공개 테스트 → 프로덕션 출시

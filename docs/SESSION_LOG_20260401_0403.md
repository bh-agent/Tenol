## 3. 신규 기능

### 3-1. 커스텀 멤버 권한 (`015d8f3`)
- DB: `club_members.custom_permissions TEXT[]` 컬럼 추가 (마이그레이션 `00029`)
- 서버: `updateMemberPermissions()` 액션, `checkMemberPermission()` 로직
- UI: 권한 관리 모달에서 토글 on/off, 저장, 기본값 초기화
- 클럽장만 변경 가능, owner 권한은 변경 불가

### 3-2. 구조화된 지역 선택 (`6104a19`, `14cd094`)
- `src/lib/constants/regions.ts`: 17개 시/도 + ~250개 시/군/구 데이터
- `src/components/ui/region-picker.tsx`: 2단 바텀시트 (소모임/플랩 스타일)
- 클럽 생성/설정 폼: 텍스트 입력 → RegionPicker 교체
- 탐색 페이지: 시/도 칩 + 시/군/구 칩 2단 필터
- 검색 쿼리: 시/도만 선택 시 `ilike` 부분 매칭
- 필터 칩 가로 스크롤 수정 (overflow-x + w-max 구조)

### 3-3. 온보딩 강화 (`22153fa`)
- **Step 1** (필수): 닉네임 + 실명 + 성별
- **Step 2** (선택): 활동 지역 (RegionPicker) + NTRP 레벨
- **Step 3** (선택): 프로필 사진 + 자기소개
- `completeOnboarding` 액션: `real_name` + `region` 저장 추가
- 실명은 대진표에 필수이므로 필수 입력으로 변경

### 3-4. 경기 결과 페이지 전면 개편 (`31028df`, `aa8e638`, `114772f`)

**새 4섹션 구조:**
1. **오늘의 MVP (Top 3)** — 평균 득점(총 득점/경기 수) 기준, 금/은/동 포디움
2. **오늘의 명장면** — 자동 감지 (최다 득점, 다승왕, 접전, 압도적 승리, 철인, 연승)
3. **재미있는 통계** — 총 득점, 완봉승, 접전율, 참여 선수
4. **게임별 결과** — 타임슬롯별 그룹, 점수 입력/수정 기능 유지

**추가:**
- 실명(닉네임) 형식 표시
- 이미지 공유 기능 (html2canvas → PNG → Web Share API / 다운로드)
- 무승부(4:4 등) 경기도 통계 반영

### 3-5. 클럽 통계 페이지 통합 수정 (`53f6295`)
1. **무승부 경기 포함**: 모든 쿼리에서 `result!=null` → `score_team_a!=null` 필터 변경
2. **동점자 모두 부여**: 업적 배지(최다참여, 연승왕, MVP), 클럽 기록(최고 점수, 최장 연승)
3. **MVP Top 3**: `getClubMvp()`가 배열 반환, 평균 득점 기준 정렬, MvpCard에 금/은/동 표시
4. **랭킹 동점 순위**: 승률+경기수 동일 시 같은 rank 부여

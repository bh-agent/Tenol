## 2. 코드 품질 요약

### 강점
- **타입 안전성**: 전체 TypeScript strict 모드, Zod 런타임 검증
- **권한 체계**: 서버 액션 + RLS 이중 보호
- **동시성 보호**: 경기 참가 원자적 RPC, 대진표 편집 잠금
- **일관된 디자인**: DESIGN.md 기반 체계적 UI 컴포넌트
- **모바일 최적화**: 터치 타겟, safe area, PWA 지원

### 개선 필요
- **테스트 없음**: 단위/통합/E2E 테스트 0건
- **에러 추적 없음**: Sentry 등 프로덕션 모니터링 미설정
- **metadataBase 미설정**: SNS 공유 시 OG 이미지 경로 문제 가능

## 5. 성능 고려사항

### 잠재적 병목
1. **피드 쿼리**: 3단계 알고리즘이 여러 테이블을 조인 — 사용자 수 증가 시 인덱스 점검 필요
2. **대진표 생성**: 참가자 20명+ 시 조합 수 증가 — 현재 합리적 범위
3. **이미지 업로드**: html2canvas로 대진표 캡처 — 클라이언트 성능 의존

### 권장 조치
- Supabase 인덱스 추가: `media.club_id`, `follows.follower_id`, `notifications.user_id+is_read`
- 피드 쿼리에 커서 기반 페이지네이션 적용 (현재 offset 방식)
- Next.js Image 컴포넌트 미사용 부분 전환 (로그인 페이지 등)

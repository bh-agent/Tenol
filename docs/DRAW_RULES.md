# 대진표 규칙 (Draw Rules)

테놀의 대진표 자동 생성 알고리즘이 따르는 규칙입니다.

## 기본 원칙

1. **인당 경기 수 균등** - 가장 중요한 규칙. 모든 참가자의 경기 수는 동일해야 하며, 나누어 떨어지지 않는 경우에만 일부가 +1경기를 합니다. 최대 차이는 1경기.
2. **성별 규칙 엄수** - 혼복은 반드시 2남+2녀, 남복은 4남, 여복은 4녀. 예외 없음.
3. **동시간대 중복 불가** - 한 선수가 같은 시간대에 두 코트에서 뛸 수 없습니다.

## 대진표 모드

### 혼복 + 남복 + 여복 (mixed_all) - 기본

가장 일반적인 모드. 세 가지 경기 유형을 자동으로 배분합니다.

**배분 규칙:**
- 남녀 비율에 따라 혼복/남복/여복 비율을 자동 계산
- 6남 6녀 기준: 혼복 약 50%, 남복 약 25%, 여복 약 25%
- 시간대별로 교차 배치 (짝수 시간대: 남복+여복, 홀수 시간대: 혼복+혼복)

**팀 구성:**
- 혼복: 1남+1녀 vs 1남+1녀 (NTRP 밸런스)
- 남복: 2남 vs 2남 (NTRP 밸런스)
- 여복: 2녀 vs 2녀 (NTRP 밸런스)

**예시 (6남 6녀, 2코트, 코트당 6경기):**
```
1경기: 1코트(남복) 2코트(여복)
2경기: 1코트(혼복) 2코트(혼복)
3경기: 1코트(남복) 2코트(혼복)
4경기: 1코트(혼복) 2코트(여복)
5경기: 1코트(남복) 2코트(여복)
6경기: 1코트(혼복) 2코트(혼복)

결과: 남복3 + 여복3 + 혼복6 = 12경기, 인당 4경기
```

### 혼복만 (mixed_only)

모든 경기를 혼복(2남+2녀)으로 진행합니다.
- 남녀 수가 맞지 않으면 일부가 대기
- 모든 코트, 모든 시간대에 혼복 경기 배치

### 남복 + 여복만 (gendered_only)

동성끼리만 경기합니다.
- 남복: 4남 vs (2남 vs 2남)
- 여복: 4녀 vs (2녀 vs 2녀)
- 남녀 비율에 따라 남복/여복 비율 자동 조정

### 자유 (free)

성별 무관, NTRP 밸런스만 고려하여 자유롭게 배정합니다.

## NTRP 밸런스 페어링

4명이 한 경기에 배정되면, NTRP를 기준으로 팀을 나눕니다.

**혼복 페어링:**
- 남자를 NTRP 높은 순, 여자를 NTRP 높은 순으로 정렬
- 높은남 + 낮은녀 vs 낮은남 + 높은녀 (서펜타인)

**남복/여복/자유 페어링:**
- 4명을 NTRP 높은 순으로 정렬
- 1번+4번 vs 2번+3번 (가장 균형 잡힌 조합)

## 경기 수 계산

```
총 경기 수 = 코트 수 × 코트당 경기 수
총 선수 슬롯 = 총 경기 수 × 4 (복식 기준)
인당 기본 경기 수 = floor(총 선수 슬롯 / 참가자 수)
추가 경기 인원 = 총 선수 슬롯 % 참가자 수
```

**예시:**
- 12명, 2코트, 코트당 6경기 → 12경기 × 4 = 48슬롯 → 48/12 = 인당 4경기 (정확)
- 10명, 2코트, 코트당 5경기 → 10경기 × 4 = 40슬롯 → 40/10 = 인당 4경기 (정확)
- 11명, 2코트, 코트당 5경기 → 10경기 × 4 = 40슬롯 → 40/11 = 3경기(8명) + 4경기(3명)

## 시간대 (타임 테이블)

- 시작 시간: 경기의 시작 시간에서 자동 가져옴
- 경기 시간: 1분 단위 조절 (기본 30분)
- N경기 = 시작시간 + (N-1) × 경기시간

**표시 형식:**
```
1경기 (20:00 ~ 20:30)
  A코트 (남복): OO OO vs OO OO
  B코트 (여복): OO OO vs OO OO

2경기 (20:30 ~ 21:00)
  A코트 (혼복): OO OO vs OO OO
  B코트 (혼복): OO OO vs OO OO
```

## 코트 이름

- 기본값: 1코트, 2코트, ...
- 커스텀 설정 가능 (예: A코트, B코트 또는 실제 코트 이름)

## 성별 오버라이드

- 대진표 생성 시 특정 선수의 성별을 임시로 변경 가능
- DB의 실제 성별은 변경되지 않음
- 사용 예: 실력 차이를 고려해 남자를 여자 그룹에 배정

## 대체 선수

- 경기 중 선수 교체 시, 기존 대진표의 모든 해당 경기에서 자동 교체
- 클럽 멤버 또는 비회원(직접 입력)으로 대체 가능

## 수동 대진표

- 자동 생성 외에 수동으로 대진표 제작 가능
- 빈 타임테이블에 선수를 직접 배치
- 자동 생성 후 수동으로 수정도 가능 (선수 교체, 게임 편집)

## 검증 규칙

대진표 생성 후 자동으로 검증하는 항목:
1. 총 경기 수 = 코트 × 코트당 경기
2. 혼복은 반드시 2남+2녀, 팀은 1남+1녀 vs 1남+1녀
3. 남복은 반드시 4남, 여복은 반드시 4녀
4. 같은 시간대 중복 배정 없음
5. 인당 경기 수 차이 최대 1
6. 같은 경기에 같은 선수 중복 없음
